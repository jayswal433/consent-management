SECURITY & ENCRYPTION IMPLEMENTATION
================================================================================

Encryption:
  • AES-256-GCM with 12-byte random IV and 16-byte auth tag
  • Data Encryption Key (DEK) from DPDP_DEK_HEX environment variable
  • Fields encrypted: name, email, phone, nominee data, optional_fields

Hashing:
  • SHA-256 for searchable encrypted fields (name_hash, email_hash, etc.)
  • HMAC-SHA256 for JWT signing/verification
  • Hash chain in audit log for tamper detection

Sensitive Data Protection:
  • IP addresses: Always hashed (ip_hash), never stored raw
  • User agents: Always hashed (user_agent_hash), never stored raw
  • Passwords: Argon2 hashed
  • Database: All PII encrypted at rest
